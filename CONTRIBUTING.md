# Contributing

1. Create a focused branch from the default branch.
2. Explain the user-visible effect and any Windows permission, network request,
   data flow, or Firebase rule change.
3. Build the WPF client and all affected web panels in Release mode and report
   the result in the pull request.
4. Update the README and security documentation when behavior, URLs,
   permissions, dependencies, or configuration changes.
5. Never commit `.env` files, service-account JSON, OAuth secrets, signing keys,
   downloaded binaries, or unreviewed third-party assets.
